rules_header
{
花札ルールと得点ガイド
}

rules_p1_title
{
1. 札の構成と月
}

rules_p1_body
{
花札は12ヶ月各4枚の計48枚で構成されます。札は光札（20点）、短冊（5点）、タネ（5点）、カス（1点）の4種類に分かれます。
}

rules_p2_title
{
2. こいこいルール (日本)
}

rules_p2_body
{
手札と同月の場札を合わせます。役（光・短冊・タネ・カス）を完成させると得点を得ます。「こいこい」で続行できますが、相手が先に役を作ると相手の勝ちとなります。
}

rules_p3_title
{
3. ゴーストップルール (韓国)
}

rules_p3_body
{
3点以上獲得でゴーかストップを宣言できます。五鳥（ゴドリ）、短冊、皮などが主な役です。3ゴー以上、光縛り、皮縛りで得点が倍増します。
}

rules_p4_title
{
4. 勝負勝利とベットモード
}

rules_p4_body
{
標準マッチは12回戦（1月〜12月）で行われます。12回戦終了時に最高得点のプレイヤーが勝利します。ベットモードでは次の札が大きいか小さいかを当てて倍増を狙います。
}
